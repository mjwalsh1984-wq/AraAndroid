# Ara for Android

A pink-themed Kotlin and Jetpack Compose Android starter project.

## Current status
This is an early UI/build scaffold, not a completed AI assistant. Chat uses a local placeholder. AI provider access, Telegram, persistent memory, background scheduling and self-development are not implemented yet.

## Build an APK
1. Open the Actions tab.
2. Select **Build Ara Android APK** and choose **Run workflow**.
3. Open the completed run and download the **ara-debug-apk** artifact.
4. Extract `app-debug.apk` and install it on Android.

Never commit API keys. Financial actions and decisions remain under the user's control. Sensitive external actions should require confirmation.
